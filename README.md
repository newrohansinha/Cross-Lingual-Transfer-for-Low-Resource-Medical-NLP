# Cross-Lingual-Transfer-for-Low-Resource-Medical-NLP
Built a clinical NLP transfer framework using Hugging Face Transformers, PyTorch, LoRA, and Gradio. Fine-tuned mBERT on 10k+ English medical NER samples, adapted to Spanish via 200 labeled examples and active learning (20→200 loop). Achieved 80%+ F1 and 2× higher data efficiency vs random sampling.
